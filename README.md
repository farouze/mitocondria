# Mitochondrial morphometry reproducibility package

Supporting materials for **Representation Bias, Correction Transfer, and Resolution Sensitivity in 3D Mitochondrial Morphometry**, by Farouk Ganiyu Adewumi and Timothy Oladunni.

- [Current manuscript: revision 18](manuscript/manuscript_revised_v18.pdf), with [editable LaTeX](manuscript/main.tex).
- [Current result-to-file map](RESULT_MAP.md).
- [Verification instructions and evidence history](reproducibility/README.md).

The original revision 14 evidence package is preserved under `reproducibility/`, including its historical manuscript and numbering. Revision 18 incorporates revision 17 wording corrections, removes the remaining unsupported residual-bias attribution, and corrects the repository URL and publication status. No new experiment is claimed.

The package includes analysis code, executed notebooks, processed results, the original frozen model and protocol, figures, and audit records. Raw source datasets are not redistributed. Some original scripts retain Colab paths; follow their documented input requirements. Archived-output verification is not a complete raw-data rerun.

The correction was evaluated within one resource. The MitoEM analysis tests regridding sensitivity, not external transfer of that correction. Biological invariance and separate contributions of every pipeline step were not established.

No new license is assigned by this upload; existing third-party terms remain applicable. GitHub publication does not itself provide a DOI. No v1.0.0 release has yet been created. The manuscript availability statement must be updated after a successful upload/release.

`UPLOAD_SHA256.json` records file integrity. Original evidence bytes are preserved; operating-system metadata is excluded. No automatic GitHub workflow is configured.
